# Review sources

These repository-specific instructions were written for Shepherd Academy Universe,
informed by Anthropic's public review approach. Upstream prose, scripts and report
templates are not vendored. The local workflow inventory and product requirements
come from this repository.

Sources checked on October 22, 2026, at upstream commit
`33d3dea41a341b341d4f5da2e8801ae0c89be2b8`:

- [Design critique](https://github.com/anthropics/knowledge-work-plugins/blob/33d3dea41a341b341d4f5da2e8801ae0c89be2b8/design/skills/design-critique/SKILL.md):
  role/context, task usability, hierarchy, consistency and specific actionable feedback.
- [Accessibility review](https://github.com/anthropics/knowledge-work-plugins/blob/33d3dea41a341b341d4f5da2e8801ae0c89be2b8/design/skills/accessibility-review/SKILL.md):
  complementary keyboard, contrast, zoom and assistive-technology checks.
- [UX copy](https://github.com/anthropics/knowledge-work-plugins/blob/33d3dea41a341b341d4f5da2e8801ae0c89be2b8/design/skills/ux-copy/SKILL.md):
  context-sensitive interface language, actions and recovery advice.

The upstream [README](https://github.com/anthropics/knowledge-work-plugins/blob/33d3dea41a341b341d4f5da2e8801ae0c89be2b8/design/README.md)
lists `ux-writing`, but the source at this revision is named `ux-copy`. Upstream
accessibility guidance targets WCAG 2.1 AA and includes enhanced target size in its
AA quick reference. This skill follows the repository's WCAG 2.2 AA target and
distinguishes AA minimum target size from AAA enhanced size using
[W3C's guidance](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html).
