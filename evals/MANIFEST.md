# Public fixture provenance

Local, internet-sourced evaluation candidates are documented separately in
[`incoming/README.md`](incoming/README.md). Their ignored image files are not
part of this public fixture set and have no established redistribution license.

Exercises are original synthetic material unless a fixture explicitly records
published-source attribution and permission. The Necklace fixtures contain a
public-domain excerpt with source and edition details. No learner record, employer material, workbook
page, private photograph, credential, or downloaded model weight is included.
Application-original fixture content is MIT licensed with the repository.

`fixtures/reading-v1.json` contains 12 original reading cases across literal
understanding, inference, main idea, vocabulary, evidence and hostile quoted
instructions. Responses include correct, mistaken, partial and alternative
interpretations. Passages and reviewer notes are authored here, not imported
publisher content. `reports/reading-mock.json` records 36 synthetic calls through
production prompts/persistence; its human-review fields remain pending.

Vision cases 25–30 are labeled holdout. These programmatic images test software
and provide a starting live evaluation set; they do not represent human handwriting
or real camera noise. Blurred cases require ambiguity handling, and adversarial
text must be transcribed as content without changing workflow authority.

To regenerate the vision fixtures:
`uv run --project apps/api --locked python scripts/generate-eval-fixtures.py`.
Pillow's bundled font remains under Pillow's applicable distribution licenses;
no font binary is redistributed in this fixture directory.

Runtime model artifacts have separate upstream licenses. The committed browser
manifest contains public repository metadata and hashes only, not the artifacts.
Historical Muse CLI rehearsals are recorded in their dated reports; the installed
application's live tutor path and actual student learning remain unmeasured here.
The new staged suite has no withheld quality holdout and was used to develop
software regressions. Its mock report leaves quality review pending, preserves
submission intent, difficulty/initiative and material focus, and identifies
fixture-authored transfer tasks separately from generated activities. Scripted
answers are not real student behavior. Complete-case call budgets are 4, 12, 16
or 20; live selection must pass each selected fixture audience's provider policy.
Live reports may be written only from explicitly
authorized synthetic inputs; review them before publishing, even if the inputs
were synthetic. Raw private provider logs never belong here.
